# تطبيق محرك النواة الذاتية (NeuroCore App Engine)

تطبيق متطور ومستقل يعمل كجسر تفاعلي بين المستخدم ونواة الذكاء الاصطناعي (NeuroCore).

---

## 📱 بناء وتحميل ملف Android APK عبر GitHub

عند رفع المشروع إلى مستودعك على GitHub (`git push`)، يتم بناء ملف الـ APK تلقائياً عبر **GitHub Actions**:

### أين تجد ملف الـ APK بعد الرفع إلى GitHub؟
1. **في صفحة الإصدارات (Releases):**
   - افتح المستودع على GitHub ثم انقر على قسم **Releases** في الجانب الأيمن.
   - ستجد أحدث إصدار وبداخله ملف **`NeuroCore.apk`** جاهزاً للتحميل المباشر وتثبيته على هاتفك.
2. **في تبويب الإجراءات (Actions / Artifacts):**
   - انتقل إلى تبويب **Actions** في مستودع GitHub.
   - اضغط على أحدث تشغيل باسم `Build NeuroCore Android APK`.
   - انزل لأسفل الصفحة إلى قسم **Artifacts** وحمّل **`NeuroCore-APK`**.

---

## 🛠️ البناء بواسطة ToAPK أو محلياً

لبناء التطبيق محلياً أو عبر أدوات بناء الـ APK:
1. **تثبيت الحزم وبناء الواجهة:**
   ```bash
   npm install --legacy-peer-deps
   npm run build
   ```
2. **مزامنة ملفات أندرويد:**
   ```bash
   npx cap sync android
   ```
3. **توليد ملف APK عبر Gradle:**
   ```bash
   cd android
   ./gradlew assembleDebug
   ```
   الملف الناتج ستجده في المسار:
   `android/app/build/outputs/apk/debug/app-debug.apk`

## ⚡ الميزات المنفذة
- **سؤال وجواب نظيف ومباشر:** تختفي المحادثات السابقة تلقائياً فور كتابة أو نطق سؤال جديد، ويظهر فقط السؤال النشط مع جواب النواة الخاص به مع خيارات التحميل والنسخ.
- **جسر النواة الذكي:** ربط ملفات النواة بصيغة ZIP، وتوليد الصور، وتطبيقات الأندرويد والآيفون، والمكالمات الصوتية الحية.
- **بناء APK أوتوماتيكي:** ملف عمل GitHub Actions متكامل (`.github/workflows/workflow.yml`) مبرمج لتوليد الـ APK ورفعه للإصدارات.
